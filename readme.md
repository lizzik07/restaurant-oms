# Система управления заказами для ресторана (Restaurant OMS)

## Описание проекта
Учебный проект в рамках курсовой работы по дисциплине «Настройка и администрирование сервисного программного обеспечения». Представляет собой веб-приложение для оформления заказов в ресторане, развернутое в кластере Docker Swarm с настроенным CI/CD.

## Структура проекта
* `frontend/` — клиентская часть (HTML, CSS, JS, Nginx).
* `backend/` — серверная часть (PHP, Apache).
* `db/` — база данных (SQLite) и скрипты инициализации.
* `proxy/` — обратный прокси-сервер (Nginx).
* `.github/workflows/` — конфигурация CI/CD пайплайна (GitHub Actions).
* `docker-stack.yml` — файл развертывания в кластере Docker Swarm.

## Запуск проекта
1. Собрать и запустить через Docker Compose: `docker compose up -d --build`
2. Открыть в браузере: `http://localhost:8080`
